# Локальный HTTP API

Сервер слушает только `http://127.0.0.1:4183`. Запросы и ответы JSON, кроме загрузки ZIP. Загрузка исходного Go-модуля требует `go.mod` в корне и Go-тестов, проходящих на исходнике. Зависимости должны быть включены в `vendor/`: сеть контейнера отключена. Ограничения: ZIP до 8 МиБ, до 300 файлов, до 256 КиБ на файл.

| Метод и путь | Роль | Действие |
| --- | --- | --- |
| `POST /v1/audits` | аудитор | ZIP в теле (`Content-Type: application/zip`); возвращает `id`, `auditorToken`, `studentToken`. |
| `POST /v1/audits/demo` | аудитор | Создаёт встроенный демонстрационный Go-проект с тремя мутациями. |
| `POST /v1/audits/github` | аудитор | JSON `{"url":"https://github.com/owner/repo"}`; фиксирует коммит по SHA. |
| `GET /v1/audits/{id}` | обе роли | Состояние, файлы, заметки и последний запуск; карта мутаций доступна только аудитору. |
| `POST /v1/audits/{id}/start` | аудитор | Начало десятиминутной защиты. |
| `PUT /v1/audits/{id}/files` | студент | JSON `{"path":"pkg/logic.go","source":"package ..."}`; тесты менять нельзя. |
| `POST /v1/audits/{id}/tests` | студент | `go test -json -count=1 ./...` в Docker. |
| `POST /v1/audits/{id}/notes` | студент | JSON `{"text":"Причина и исправление","path":"pkg/logic.go","line":14}`; путь и строка необязательны. |
| `POST /v1/audits/{id}/finish` | обе роли | Финальная проверка и закрытие сессии. |
| `GET /v1/audits/{id}/report` | аудитор | Итог, мутации, правки, заметки, результаты тестов. |

Передавайте токен роли через `Authorization: Bearer <token>`. Студенту выдаётся только `studentToken`. Тесты могут подтвердить восстановленное поведение только в пределах их покрытия; понимание оценивает аудитор. Сессии на сервере сбрасываются после перезапуска.
