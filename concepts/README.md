# Studio: защита и история в локальном макете

Откройте `http://127.0.0.1:4184/studio.html` (или файл `studio.html` в браузере).

- **«Новая защита»** создаёт следующий номер и уникальный SHA-256 ID защиты, сохраняя историю предыдущих.
- Каждый ручной запуск и итоговая проверка получают последовательный номер, SHA-256 ID и SHA-256 текущего исходника.
- Каждая из трёх проверок (`TestBoundary`, `TestAccess`, `TestRemaining`) внутри запуска получает свой номер и SHA-256 ID.
- **«История тестов»** показывает все локально сохранённые защиты и прогоны, включая предыдущие сессии после перезагрузки страницы. Активная защита возобновляет свой отсчёт после обновления страницы.

ID строится из времени, номера, случайного значения и контекста запуска; хэш исходника отдельно вычисляется из текста `sample.go`. Хэш-ID нужен для идентификации записи, он **не доказывает**, что Go-код верен. Запуски в этом HTML-файле имитируются по встроенным трём выражениям и не обращаются к бэкенду. Сохранение происходит в `localStorage` текущего браузера и origin; очистка данных сайта удалит историю. Для реальной защиты используйте сервер на `http://127.0.0.1:4183/`.

Проверка макета на установленном Windows Chrome: `node --test concepts/studio.e2e.cjs` из корня проекта, при запущенном статическом превью на порту 4184.
