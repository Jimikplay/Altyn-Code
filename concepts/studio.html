Демо / отдельная роль

Три изменения.
Три гипотезы.

Встроенный пример из demo.go: исходный проект проходил тесты, затем в трёх функциях заменили по одному оператору. Ниже — карта, которую видит аудитор до начала защиты.

01
Eligible

Граница допуска

score >= 70 → score > 70

Значение 70 перестало проходить.

02
CanEnter

Проверка доступа

active && credits > 0 → active || credits > 0

Кредитов стало достаточно даже без активности.

03
Remaining

Остаток кредитов

total - used → total + used

Остаток стал расти после расхода.

Карта показывает сценарий этой локальной иллюстрации; она не получена из запущенного аудита.
