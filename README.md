# Altyn Code

Прототип P2P-защиты Go-проектов: движок вносит три проверяемые тестами мутации, студент исправляет код за 10 минут, аудитор просматривает результат и объяснение.

**[Открыть Studio — публичный интерактивный макет](https://jimikplay.github.io/Altyn-Code/)**. В нём есть новые защиты, история и SHA-256 идентификаторы каждого запуска и теста. Макет имитирует проверки в браузере; **на GitHub Pages Go-код не исполняется**.

## Запустить настоящий движок локально

Нужны Go 1.22+, Docker Desktop с Linux-движком и образ `golang:1.27.3-alpine`.

```powershell
docker pull golang:1.27.3-alpine
go run ./cmd/auditd
```

Откройте **http://127.0.0.1:4183/** и нажмите «Создать демо-аудит» (подготовка занимает несколько минут). Можно загрузить ZIP Go-модуля или импортировать публичный GitHub-репозиторий. Тесты запускаются только в ограниченном Docker-контейнере, а не на компьютере пользователя.

## Что внутри

- `engine.go`, `runner.go`, `session.go`, `api.go` — анализ Go AST, изолированные тесты, роли, таймер и HTTP API.
- `static/` — минимальная тестовая страница настоящего бэкенда.
- `concepts/studio.html` — выбранный визуальный прототип; `concepts/` содержит также два альтернативных дизайна.
- `docs/API.md` и `docs/TESTING.md` — эндпоинты, ограничения и проверки.

Проверки: `go test -short ./...` (быстрые) и `go test ./...` (включая Docker). История на публичной Studio-странице хранится в `localStorage` браузера; серверные сессии локального бэкенда пока хранятся в памяти и не доступны через GitHub Pages.
