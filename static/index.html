Что будет дальше

  1. ПроверкаСначала исходный проект должен пройти тесты.
  2. МутацииДвижок ищет три изменения, которые тесты действительно замечают.
  3. ЗащитаСтудент исправляет код; аудитор видит результат и объяснения.

Здесь обе роли показаны в одном окне только для ручной проверки. Права доступа проверяет сервер.
